# Mahil Gaila Dussehra Website

A responsive, multilingual, client-based website for the Mahil Gaila Dussehra and Shri Ramleela Mahotsav celebration. This project presents festival information, event schedules, downloadable scripts, photo galleries, video highlights, cast details, and contact information in a modern and elegant web experience.

## Project Overview

This website is designed to serve as a digital showcase and information portal for the Mahil Gaila Dussehra event. It provides visitors with an easy way to explore:

- Festival history and event information
- Event and celebration schedules
- Navratri script resources
- Photo galleries from previous years
- Video gallery highlights
- Cast and performer information
- Contact details for enquiries

The website is built as a static front-end project using HTML, CSS, and JavaScript, making it lightweight, fast, and easy to deploy.

## Purpose of the Project

This website was created to:

- Present the festival in a polished digital format

## How to Run Locally

This is a static website, so no build tools are required.

1. Open the project folder in your code editor.
2. Start a local server or open [index.html](index.html) directly in a browser.
3. For a better experience, use a simple local server such as:
   - VS Code Live Server
   - Python HTTP server
   - Node-based static server

Example using Python:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
